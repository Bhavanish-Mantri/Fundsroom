# Mini ERP Assessment

This repository contains the initial project scaffold for a small PERN-based mini ERP application focused on the required assessment workflow.

## Structure

- `backend/` — Express.js API and PostgreSQL-backed business logic
- `frontend/` — React frontend
- `docs/` — assessment specification and design documents

## Phase 1 status

This is the initialization phase only. The project structure and baseline configuration are in place.

## Planned stack

- React.js
- Node.js + Express.js
- PostgreSQL
- Prisma
- JWT auth
- Jest + Supertest

## Notes

- No Docker, Redis, or unnecessary services are included.
- No application logic has been implemented yet.
- The next phase will be PostgreSQL schema and migration setup.
